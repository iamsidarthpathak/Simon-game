# 🎮 Simon Game

A classic memory game built with HTML, CSS, and Vanilla JavaScript. Test your memory by repeating the increasingly long sequence of flashing colors!

## 🚀 Live Demo
[Click here to play the game!] https://iamsidarthpathak.github.io/Simon-game/


## 📖 About the Project
I built this Simon Game to strengthen my core JavaScript skills. The main focus of this project was to master:
* Managing game state and memory using JavaScript arrays.
* Handling asynchronous timing events with `setTimeout`.
* DOM manipulation and injecting dynamic CSS classes.
* Comparing complex sequences of user input against randomized data.



## ✨ Features
* **Dynamic Gameplay:** Sequence gets longer and faster with each level.
* **Strict Mode:** One wrong click and it's Game Over.
* **High Score Tracking:** Remembers your best session score.


## 🛠️ Technologies Used
* **HTML5:** Semantic structure.
* **CSS3:** Styling, grid layout, and flash animations.
* **JavaScript (ES6):** DOM manipulation, event listeners, array tracking, and game logic.
